# SVR Tyres — Inventory & Billing Management System

A web-based inventory and billing system built for a tyre shop, handling stock management, billing, invoicing, and sales analytics — all in the browser.

## Features
- Add, edit, delete tyre stock with low-stock and out-of-stock alerts
- Search and filter inventory by brand or size
- Billing flow with cart, automatic 18% GST calculation, and printable invoices
- One-click invoice sharing via WhatsApp
- Sales dashboard with Chart.js visualizations (sales and profit trends)
- Customer purchase history and CSV export
- Data persistence using browser LocalStorage — no backend required

## Tech Stack
HTML, CSS, JavaScript, Chart.js, LocalStorage

## How to Run
Clone the repo and open `index.html` directly in a browser — no build step or server needed.

**Demo login:** username `admin`, password `1234` (hardcoded for demo purposes only — not production authentication)
